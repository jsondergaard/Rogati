# @jsondergaard/rogati-core

The consent decision, with no opinion about how it is asked. A synchronous gate
that is denied until somebody says otherwise, a policy that declares what the
site stores, and adapters for PostHog, Google Consent Mode v2, Plausible,
Fathom and Meta Pixel.

Pair it with `@jsondergaard/rogati-react` or `@jsondergaard/rogati-vanilla` for the banner and dialog.

Documentation: https://github.com/jsondergaard/Rogati
